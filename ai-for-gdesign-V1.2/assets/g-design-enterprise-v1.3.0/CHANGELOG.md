# Changelog

## 1.3.0

- 新增 Aurora Glass 视觉扩展，包含蓝—淡紫—浅粉展示型渐变、Light / Dark 磨砂玻璃 Token 和三种可复用玻璃表面类。
- 新增玻璃效果降级策略，并将视觉风格与生成规则登记到资产 manifest。
- 内置Lucide Static 1.43.0完整离线SVG资源。
- GIcon升级为离线按名渲染，并支持中文语义别名。
- 新增图标索引、标签、许可证、第三方声明和完整性检查。

## 1.2.0

- 新增9个高频基础组件和9个常用业务组件。
- 六类页面模板统一接入PageStateShell。
- 新增保存、删除与批量操作反馈模式。
- 资产总量升级至67项。

## 1.1.0

- 补齐34个常用基础组件并统一为独立资产目录。
- 为每个组件增加类型、样式、元数据、说明和示例。
- 增加 Message、Notification、Loading 函数式服务适配。
- 扩展G Design组件级Token与AI资产目录。

## 1.0.0

- 建立 G Design Token 的 Light / Dark 工程化主题。
- 锁定 Element Plus 2.13.5。
- 新增基础、业务、复杂组件和六类页面模板。
- 新增拓扑交互、告警影响和机器可读资产元数据。
