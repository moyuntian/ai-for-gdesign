# 质量检查

- [ ] 仅使用有效的 HEX、RGB、RGBA 和 CSS 变量
- [ ] Light / Dark 下信息层级清楚
- [ ] 键盘可达并具有可见焦点
- [ ] 覆盖加载、空、错误、禁用和无权限状态
- [ ] 表格批量操作仅在选中后可用
- [ ] 拓扑状态不只依赖颜色，并提供图例
- [ ] 组件目录含实现、入口与机器可读元数据
- [ ] 页面模板引用公共组件，不重复复制
- [ ] Element Plus 版本固定为 2.13.5
- [ ] 六个页面模板均声明 loading、empty、error、forbidden、partial、ready
- [ ] 保存提供成功和失败反馈
- [ ] 删除操作需要二次确认
- [ ] 批量操作反馈包含处理数量或失败项
